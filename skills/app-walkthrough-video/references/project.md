# Project folder and project.json

```
my-film/
  project.json            everything configurable (below)
  logo.png                square, transparent, ~256 px
  script/
    beats.json            chapters + beats (required)
    translations.json     {"b0101": {"km": "...", "zh": "..."}, ...}   one entry per beat, per extra language
    ui_<lang>.json        chapter titles, label translations, FAQ, card words for each non-base language
    slots.json            footage the user films themselves (shown as a dashed placeholder until replaced)
    faq.json              FAQ cards for the base language: {"b1201": {"q": "...", "a": "..."}}
    ad.json               2-minute ad script (optional)
    lexicon_<lang>.json   pronunciation fixes for the voice (optional, see voice.md)
  rec/scenes.mjs          the recorded takes (see recording.md)
  voice/                  reference recordings for cloned voices
  clips/<scene>/          clip.mp4 + events.json per take            (generated by rec.sh)
  tts/<lang>/<beat>.wav   voice lines                                  (generated by voice.sh)
  tts_ad/<lang>/          ad voice lines                               (voice.sh --ad)
  build/                  timelines, Remotion public dir, timing, QC  (generated)
  out/                    finished videos, SRTs, docs, covers, parts  (generated)
```

Copy `examples/gennal-walkthrough` to start; it is a complete real project.

## beats.json

```json
{"title": "GenNal: every feature, start to finish", "version": "1.5.9",
 "chapters": [{"id": "c01", "title": "Intro"}, {"id": "c05", "title": "Agents Window"}],
 "beats": [
   {"id": "b0101", "ch": "c01", "label": "GenNal", "shot": "intro-montage", "vo": "This is GenNal: ..."},
   {"id": "b0505", "ch": "c05", "label": "Queued message", "shot": "agents-queue",
    "action": "Type a follow-up while the reply streams → Queue message", "vo": "Keep typing while it works..."}]}
```
- `vo` is the narration in the base language; `label` is the on-screen tag (top left).
- `shot` is one of: a shot id marked in a scene (`s.shot('agents-queue')`), a website-tour key from
  `edit.site_shots`, a whole clip from `edit.whole_clips`, a key in `slots.json`, or the specials
  `intro-montage`, `faq-card`, `end-card`.
- One beat = one VO line = one idea, 1–3 sentences. 60–80 beats ≈ 13–15 min.

## project.json

| key | meaning |
|---|---|
| `name`, `slug` | product name; slug prefixes every output file |
| `base_lang`, `langs`, `subtitles` | script language; voice languages to produce; subtitle tracks for every video |
| `brand` | `name`, `logo`, `url` (end card), `tagline` (ad brand slide), `accent` [two hex colours] |
| `spoken_url` | how the VO says the URL per language ("gen-nal dot onrender dot com") → captions show the real URL |
| `asr_hint` | words Whisper should expect (product names) for the voice QC |
| `redact`, `redact_css` | regexes blurred in any text on screen (emails always); CSS selectors blurred (QR codes) |
| `app` | how to launch and drive the app (recording.md) |
| `site` | website tour: `url`, `stops` [[selector, label, hold_ms]], `lang_switch`, `mobile_menu`, `host_map` |
| `voice` | per language: `ref_wav` + `ref_text` (clone) or `design` + `sample_text` (designed voice) |
| `music` | optional own tracks: `{"walkthrough": "music/bed.wav", "ad": "music/ad.wav"}` (default: built-in) |
| `edit.site_shots` | `"site-tour:faq": ["site-tour", "System requirements", "FAQ"]` = from label A to the end of label B |
| `edit.whole_clips`, `edit.portrait_clips` | clips used whole; clips shown in a phone frame |
| `edit.continue` | `{"sessions-restart": "sessions-restart-2"}` play a second take right after (e.g. across an app restart) |
| `edit.montage` | intro montage: [[shot, offset_s, length_s], ...] split over the first two intro beats |
| `edit.vertical` | 9:16 cut: [{"beat", "title": {lang: text}, "skip": [langs], "fallback_shot"}] |
| `ad` | `seconds`, `langs`, `cta` per language |
| `covers` | per language: `thumb`, `vertical` ({shot, offset, lines, sub, badge}) and `parts` [[line1, line2, sub]] |
| `publish` | per language: YouTube `title`, `description`, `tags`, `hashtags`, and `facebook` / `short` / `x` / `part_caption` texts (`{url}`, `{tags}` are filled in) |
